JenkinsAsService

Summary

A .NET 10 Windows Service that runs a Jenkins Agent (JNLP/inbound) natively. Includes an event-driven watchdog with auto-recovery, secret protection (TPM/DPAPI/CredMgr/EnvVar), structured logging with Serilog, an integrity-checked jar cache, and optional OpenTelemetry metrics. Eliminates the need for manual agent startup, login sessions, or scheduled tasks.
